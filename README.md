# 🎓 University Management System

A C++17 and Qt6-based desktop application for managing university-related activities and academic information.

## ✨ Features

* Student Management
* Faculty Management
* Course Management
* Department Management
* Marks & Grades
* Exam Management
* Residence Management
* Sports Management
* Student Search

## 🛠️ Tech Stack

* C++17
* Qt6
* CMake
* Object-Oriented Programming

## 🚀 Build & Run

```bash
git clone https://github.com/chinmayee302006/university-management-system.git
cd university-management-system

mkdir build
cd build
cmake ..
cmake --build .
```

Run the generated application after the build completes.
